# PMP_Midset
Issue Process
1. Identify Issue
   (Phát hiện vấn đề)

2. Log the Issue
   (Ghi vào Issue Log)

3. Assess / Analyze
   (Phân tích nguyên nhân và tác động)

4. Consult / Collaborate
   (Làm việc với team, SME, stakeholder liên quan)

5. Determine Response
   (Lựa chọn phương án xử lý)

6. Implement Response
   (Thực hiện phương án)

7. Monitor Results
   (Theo dõi hiệu quả xử lý)

8. Update Project Documents
   (Issue Log, Lessons Learned, Reports...)

9. Escalate
   (Nếu vượt thẩm quyền PM)

10. Change Request
    (Nếu ảnh hưởng baseline hoặc cần thay đổi được kiểm soát)

11. Close Issue
    (Đóng issue khi đã giải quyết)
